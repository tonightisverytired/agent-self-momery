# dnamemory 开箱即用手册

> 版本：v1.0（2026-08-03）｜适用版本：0.3.0

## 0. 开箱即用评估结论

**结论：当前开箱即用能力满足基础需求，手册可编写。**

评估依据：

| 需求 | 是否开箱满足 | 说明 |
|---|---|---|
| 安装即用 | ✅ | `pip install .` 后 CLI/API 可用，零配置文件 |
| 有数据可体验 | ✅ | `dnamemory demo` 一键生成 40 事件演示库 |
| 基础召回（时间+图谱+词面语义） | ✅ | 纯标准库依赖，双路/三路可直接跑 |
| 真实语义检索 | ⚠️ 需 extras | `pip install .[embed]` + 首次运行自动下载 bge-m3 |
| 重排 | ⚠️ 需 extras | `pip install .[embed]` + 下载 bge-reranker-v2-m3 |
| 向量索引 | ⚠️ 需 extras | `pip install .[vector]`；未装自动回退 numpy |
| 服务化 | ⚠️ 需 extras | `pip install .[server]` / `.[mcp]` |

基础能力（FR-01/03/06-10/14）开箱即用；增强能力（FR-05/12/13、bge-m3 语义）按需安装 extras，因此手册按"基础 + 增强"两级编写。

## 1. 环境要求

- Python 3.10+
- 可选：`pip` 可用；语义模型约需 2.3GB 磁盘与联网（首次）

## 2. 安装

```powershell
pip install dnamemory                 # 基础（零可选依赖）
pip install dnamemory[embed]          # + bge-m3 语义路 / reranker
pip install dnamemory[vector]         # + sqlite-vec 向量索引
pip install dnamemory[server]         # + FastAPI 侧车
pip install dnamemory[mcp]            # + FastMCP 服务
pip install dnamemory[dev]            # + pytest 开发依赖
```

本仓库开发安装：

```powershell
pip install -e .[dev,vector]
```

## 3. 快速开始（CLI）

```powershell
# 1) 生成演示库（40 条事件，seed=42）
dnamemory demo --db user_memory.db

# 2) 写入一条记忆
dnamemory add-event --name "与张总讨论项目A预算" --ts 2026-08-03 --db user_memory.db

# 3) 召回
dnamemory recall --text "预算" --k 5 --db user_memory.db
dnamemory recall --topic 项目A --k 5 --db user_memory.db

# 4) 月度反射压缩
dnamemory reflect --year 2026 --month 8 --db user_memory.db

# 5) 遗忘（普通/合规删除）
dnamemory forget --target 1 --reason retracted --db user_memory.db
dnamemory forget --target 1 --reason gdpr --force --db user_memory.db
```

退出码：0 成功；1 业务/运行错误；2 参数用法错误。业务错误输出到 stderr，格式 `Error <code>: <message>`。

## 4. 快速开始（Python API）

```python
from dnamemory import MemorySystem, RecallQuery

mem = MemorySystem(path="user_memory.db")
mem.add_event("与张总讨论预算", None, kind="meeting", value_score=0.6)
mem.add_entity("张总", "person", "项目负责人")

hits = mem.recall(RecallQuery(text="预算"), k=5, mode="triple",
                  node_types=("event",))
for h in hits:
    print(h.name, h.score)

mem.forget(hits[0].node_id, reason="retracted")   # 普通遗忘
mem.close()
```

### 4.1 记忆 Runtime（0.5.0）：状态解析 / 时间线 / 解释

```python
from datetime import datetime
from dnamemory import MemorySystem, RecallQuery

mem = MemorySystem(path="user_memory.db")
u = mem.add_entity("用户", "person")
mem.add_fact(u, "city", "南京", source="profile", confidence=0.9,
             valid_at=datetime(2025, 8, 1), invalid_at=datetime(2026, 7, 1))
mem.add_fact(u, "city", "上海", source="profile", confidence=0.9,
             valid_at=datetime(2026, 7, 1))

# 结构化上下文（QueryRouter 自动路由；当前事实由确定性规则裁决）
ctx = mem.recall_context(RecallQuery(text="我现在住哪里"),
                         query_time=datetime(2026, 9, 1))
print(ctx.query_type, [f.value for f in ctx.current_state])  # current_state ['上海']

# 实体时间线 / 维度历史 / 记忆解释（Memory+Evidence+Version+Source+Related）
mem.timeline(entity_id=u, start=datetime(2025, 1, 1))
mem.memory_history(u, dimension="fact")
mem.explain(2, kind="fact")   # 无证据记忆抛 E013（不编造）
mem.close()
```

CLI 对应命令：

```powershell
dnamemory history --entity 用户 --dimension fact --db user_memory.db
dnamemory timeline --entity 用户 --start 2025-01-01 --end 2026-09-01 --db user_memory.db
dnamemory context "我现在住哪里" --db user_memory.db
dnamemory explain 2 --kind fact --db user_memory.db
```

## 5. 启用增强能力

### 5.1 bge-m3 真实语义路（推荐）

```python
from dnamemory import MemorySystem
from dnamemory.embeddings import BGEM3Embedder

mem = MemorySystem(path="user_memory.db", embedder=BGEM3Embedder())
```

首次使用自动下载 `BAAI/bge-m3` 并缓存；之后离线加载。写入节点时自动生成 1024 维稠密向量 + 词级稀疏权重。

### 5.2 稀疏第四路（quad）

```python
hits = mem.recall(RecallQuery(text="买菜做饭"), k=5, mode="quad",
                  node_types=("event",))
```

### 5.3 重排

```python
from dnamemory.rerank import BGEReranker

mem = MemorySystem(path="user_memory.db", embedder=BGEM3Embedder(),
                   reranker=BGEReranker())
```

`BAAI/bge-reranker-v2-m3` 首次使用自动下载（约 2GB）；失败/异常自动回退原排序。

### 5.4 sqlite-vec 向量索引

```powershell
pip install dnamemory[vector]
```

```python
mem.store.rebuild_vector_index("BAAI/bge-m3", 1024)  # 手动重建
```

未安装/加载失败时自动回退 numpy 暴力检索，结果一致。

### 5.5 FastAPI 侧车

```powershell
pip install dnamemory[server]
py -m server.main --path user_memory.db --token <token>
py -m server.main --path user_memory.db --token <token> --bge-m3
py -m server.main --path user_memory.db --token <token> --bge-m3 --reranker
```

说明：`--bge-m3` 加载语义模型（`DNAMEMORY_BGE_PATH` 指向本地目录则离线加载，否则首次自动下载）；`--reranker` 加载重排模型（`DNAMEMORY_RERANKER_PATH`）；抽取器默认自动接线——配置了 `DEEPSEEK_API_KEY` 即启用「LLM 优先 + 失败兜底」链（`DEEPSEEK_MODEL` 可换模型），`/write` 写入自动解析事实与相对时间（昨天/上周→具体日期）；`--fallback-extractor` 强制确定性兜底（离线/测试用，不做 LLM 抽取）；两者都没有时写入报 E010。旧数据如需语义检索，需先用带 embedder 的进程回填向量。无 token 启动直接拒绝；请求无 Authorization 返回 401。

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/health -Headers @{Authorization="Bearer <token>"}
Invoke-RestMethod -Uri http://127.0.0.1:8000/recall -Method Post `
  -Headers @{Authorization="Bearer <token>"} -ContentType "application/json" `
  -Body '{"text":"预算","k":5}'
```

无 token 启动直接拒绝；请求无 Authorization 返回 401。

### 5.6 FastMCP 服务

```powershell
pip install dnamemory[mcp]
py -m app.dnamemory_mcp --path user_memory.db                    # stdio
py -m app.dnamemory_mcp --transport streamable_http --token <token> --port 8765
```

工具：`dnamemory_recall` / `dnamemory_write_memory` / `dnamemory_forget` / `dnamemory_resolve_conflicts`。

### 5.7 可插拔检索后端（0.4.0）

```powershell
pip install dnamemory[pg]          # Postgres 时间链
pip install neo4j                  # Neo4j 空间链（独立可选）
```

```python
from dnamemory import MemorySystem
from dnamemory.backends.postgres import PostgresTimeBackend
from dnamemory.backends.neo4j import Neo4jGraphBackend

mem = MemorySystem(
    path="user_memory.db",
    time_backend=PostgresTimeBackend("postgresql://..."),
    graph_backend=Neo4jGraphBackend("bolt://127.0.0.1:7687",
                                    auth=("neo4j", "dnatest2026")),
)
```

说明：默认不注入时零抽象开销；后端查询只读，写入仍走 SQLite；数据需先用同步函数预置（见 [后端选型.md](后端选型.md)）。

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| `E010 抽取器未注入` | `write_text` 需要 `extractor`，结构化写入用 `add_event/add_entity` 等 |
| 语义路无结果 | 确认 `pip install dnamemory[embed]` 且模型已缓存；检查 `dense_min_sim`（默认 0.55） |
| FlagEmbedding 导入慢/卡住 | 设置 `HF_HUB_OFFLINE=1` 走本地缓存 |
| 向量写入报 `E011` | embedder 未返回稠密向量或维度为空 |
| `forget --force` 后 restore 失败 | 合规删除为终态，deleted 不可恢复（E004） |
| 端口被占 | `--port` 换端口；默认 8000/8765 |
| 多进程读同一库 | 本期仅支持单进程单库；并发写由库内单写锁串行化 |
