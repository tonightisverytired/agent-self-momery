# dnamemory 功能清单

> 版本：v1.0（2026-08-03）｜适用版本：0.3.0

## 1. 核心库功能

| 类别 | 功能 | 入口 | 状态 |
|---|---|---|---|
| 写入 | 事件/实体/关联边/事实结构化写入 | `MemorySystem.add_*` | ✅ 已实现 |
| 写入 | LLM 文本拆解（Pydantic 逐条校验、幂等） | `write_text / write_many` + `DeepSeekExtractor` | ✅ 已实现 |
| 召回 | 时间路 | `recall(mode="time")` | ✅ 已实现 |
| 召回 | 图谱路（14 类关联边、BFS 多跳） | `recall(mode="graph")` | ✅ 已实现 |
| 召回 | 稠密语义路（bge-m3，阈值 0.55） | `recall(mode="semantic/triple")` | ✅ 已实现 |
| 召回 | 稀疏第四路（bge-m3 lexical weights，阈值 0.25） | `recall(mode="quad")` | ✅ 已实现 |
| 召回 | RRF 融合 + 过滤链 + 并列规则 | `recall(k, filters, mode)` | ✅ 已实现 |
| 召回 | 可选重排（rerank_top_n=20，失败回退） | `MemorySystem(reranker=...)` | ✅ 已实现 |
| 治理 | 生命周期状态机（非法迁移拒绝） | `store.update_lifecycle` | ✅ 已实现 |
| 治理 | 受控衰减/价值加固/保护区 | `step_day / access` | ✅ 已实现 |
| 治理 | 普通遗忘（墓碑）/ 合规删除（deleted+级联） | `forget(force=...)` | ✅ 已实现 |
| 治理 | 恢复（deleted 拒绝） | `restore` | ✅ 已实现 |
| 治理 | 冲突治理（来源可信级/superseded_by/confirm） | `resolve_conflicts / confirm` | ✅ 已实现 |
| 治理 | 事实版本链 | `fact_history(entity, key)` | ✅ 已实现 |
| 治理 | 访问控制（sensitive 隐藏） | `access_label` + `RecallFilters` | ✅ 已实现 |
| 治理 | 反射压缩（月度摘要/主题簇/敏感级继承） | `reflect_monthly` | ✅ 已实现 |
| 治理 | 实体消解（同名合并/端点模糊匹配/自边清除） | `resolve_entities` + 写入管线 | ✅ 已实现 |
| 存储 | SQLite 事务/幂等/审计/墓碑/版本 | `SQLiteStore` | ✅ 已实现 |
| 存储 | sqlite-vec 余弦 ANN（自动重建/增量/降级） | `store.rebuild_vector_index / search_vectors` | ✅ 已实现 |
| 存储 | Postgres DDL 与设计占位 | `pg_store` / `tools/pg_migrate.py` | ⏸ 设计占位 |

- PostgresStore 完整实现（仅 DDL+占位）；
- LongMemEval 官方仓库适配器；
- 多进程共享同一库文件；
- 模型权重的离线打包分发。
