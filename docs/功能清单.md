| 写入 | 事件/实体/关联边/事实结构化写入（0.8.1 起 add_event/add_entity/add_fact 支持 evidence_ids） | `MemorySystem.add_*` | ✅ 已实现 |

| 状态 | 确定性查询意图路由（当前/历史/时间线/变化，无 LLM） | `resolve.query_router` | ✅ 已实现 |

| 评分 | MemoryScore 分项评分（仅 recall_context 管线，recall 零变化） | `models.MemoryScore` | ✅ 已实现 |
| 写入 | LLM 文本拆解（Pydantic 逐条校验、幂等） | `write_text / write_many` + `DeepSeekExtractor` | ✅ 已实现 |
| 召回 | 时间路 | `recall(mode="time")` | ✅ 已实现 |
| 召回 | 图谱路（14 类关联边、BFS 多跳） | `recall(mode="graph")` | ✅ 已实现 |
| 召回 | 词面路（0.8.1 重写：中文 bigram 包含度，`lexical_min_score` 准入阈值 0.15 作用于包含度，价值分只参与排序） | `recall`（text 查询恒在，路径名 `lexical`） | ✅ 已实现 |
| 召回 | 稠密语义路（bge-m3，阈值 0.55；0.8.1 起与词面路并行互不稀释） | `recall(mode="semantic/triple")` | ✅ 已实现 |

| 治理 | 生命周期状态机（非法迁移拒绝） | `store.update_lifecycle` | ✅ 已实现 |
| 治理 | 受控衰减/价值加固/保护区 | `step_day / access` | ✅ 已实现 |
| 治理 | 普通遗忘（墓碑）/ 合规删除（deleted+级联） | `forget(force=...)` | ✅ 已实现 |
