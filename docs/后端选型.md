# dnamemory 后端选型

> 日期：2026-08-05｜适用版本：0.4.0
> 依据：[评估报告-Postgres与Neo4j替换.md](./评估报告-Postgres与Neo4j替换.md)、[开发计划-可插拔后端.md](./开发计划-可插拔后端.md)

## 1. 决策表

| 场景 | 推荐配置 | 理由 |
|---|---|---|
| 单进程、边 < 5 万、常规个人助手 | **默认（SQLite 内置）** | 零配置、零抽象开销、延迟最低 |
| 多进程共享、十万级以上时间链、需要在线备份 | 默认 + `PostgresTimeBackend` | 并发/运维能力，时间路结果与默认一致 |
| 十万边以上、深多跳（hop≥3）/路径分析 | 默认 + `Neo4jGraphBackend` | 图遍历 4.6ms vs Python BFS 397ms（10 万边） |
| 混合 | 同时注入 time+graph 后端 | 两条链独立可插拔 |

## 2. 注入示例

```python
from dnamemory import MemorySystem, RecallQuery
from dnamemory.backends.postgres import PostgresTimeBackend
from dnamemory.backends.neo4j import Neo4jGraphBackend

mem = MemorySystem(
    path="user_memory.db",
    time_backend=PostgresTimeBackend(
        dsn="postgresql://dnatest:dnatest@127.0.0.1:5433/dnamemory"),
    graph_backend=Neo4jGraphBackend(
        uri="bolt://127.0.0.1:7687", auth=("neo4j", "dnatest2026")),
)
hits = mem.recall(RecallQuery(time=..., topic=["项目A"]), mode="triple")
```

说明：

- `time_backend`/`graph_backend` 缺省为 `None`，此时检索走内置 SQLite 直连路径（零派发）；
- 后端为查询只读：写入仍走 SQLite，数据需先用 `sync_memory_to_postgres` / `sync_memory_to_neo4j` 预置；
- `MemorySystem.close()` 会自动关闭注入的后端连接；
- 后端连接失败抛 `E009`，不影响默认路径。

## 3. 验证性能数据（2026-08-05，docker 本地）

时间链（p50 ms）：

| 规模（事件/边） | SQLite | Postgres | Neo4j |
|---|---:|---:|---:|
| 20k / 52k | 0.29 | 4.26 | 9.29 |
| 40k / 102k（hop 无关） | 1.33 | 3.87 | 13.36 |
| 100k / 252k | 5.32 | 21.22 | 27.20 |

空间链（p50 ms）：

| 规模（事件/边） | SQLite Python BFS | Postgres CTE | Neo4j |
|---|---:|---:|---:|
| 20k / 52k（hop 2） | 69.3 | 6.9 | 6.7 |
| 40k / 102k（hop 3） | 142.6 | 13.6 | 15.2 |
| 100k / 252k（hop 2） | 397.2 | 18.4 | 4.6 |

正确性：三后端与 SQLite 结果集在所有档位全等；Neo4j 注入后 top-k 与默认路径完全一致。

## 4. 容器启动（本地验证用）

```powershell
docker run -d --name dnamemory-pg -e POSTGRES_PASSWORD=dnatest `
  -e POSTGRES_USER=dnatest -e POSTGRES_DB=dnamemory -p 5433:5432 postgres:15-alpine
docker run -d --name dnamemory-neo4j -e NEO4J_AUTH=neo4j/dnatest2026 `
  -p 7687:7687 -p 7474:7474 neo4j:2025.03.0-community-bullseye
```

## 5. 注意事项

- Neo4j Community 为 GPLv3；商用部署需评估许可证与运维成本；
- Postgres 时间路延迟包含网络往返，小数据量下慢于进程内 SQLite；
- 后端集成测试需要 `DNAMEMORY_PG_DSN` / `DNAMEMORY_NEO4J_URI` 环境变量，CI 默认跳过。
