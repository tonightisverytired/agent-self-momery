# dnamemory 后台人工验收清单（0.8.0）

> 自动化已验证：静态资源 200、API 不被遮蔽、鉴权、读写全流程（见 tests/test_web_static.py、tests/test_api_graph.py 与 curl 端到端记录）。
> 本清单覆盖浏览器交互行为（零构建 JS 无单测，人工验收）。
> 后台为侧边栏六页导航：仪表盘 / 图谱 / 浏览 / 查询 / 写入 / 治理。

## 启动

```powershell
dnamemory-server --path user_memory.db --token demo --fallback-extractor
# 浏览器打开 http://127.0.0.1:8000/
```

## 验收步骤

| # | 区块 | 操作 | 预期 |
|---|---|---|---|
| 1 | 顶栏 | 不配 token 直接点「刷新统计」 | 状态灯红色「未连接」+ 401 toast |
| 2 | 顶栏 | 填入 `demo` 点「保存」 | 状态灯绿色「已连接」+ 统计卡自动加载 |
| 3 | 侧边栏「仪表盘」 | 记录统计数值 | 各卡大数字与 `GET /stats` 一致；active 小字与 `GET /graph` counts 一致；四组分布横条（节点类型/边关系/生命周期/访问标签）与最近事件表渲染；底部「原始 JSON」可展开核对 |
| 4 | 侧边栏「写入」 | 选 `entities` 填 name=用户 → 写入 | 结果区显示 `id = N`；仪表盘「实体」+1 |
| 5 | 侧边栏「写入」 | 选 `facts` 填 实体=用户 / key=city / value=上海 → 写入 | 返回 id；仪表盘「事实」+1 |
| 6 | 侧边栏「写入」 | 选 `impacts` 填 主体=用户 / 维度=income / direction=increase / valence=positive → 写入 | 返回 id；仪表盘「影响」+1 |
| 7 | 侧边栏「浏览」 | 实体=用户、key=city → 查事实 | 事实表格 value 列显示「上海」（点「原始 JSON」可核对 `"value": "上海"`） |
| 8 | 侧边栏「查询」 | 未查询时先看查询台 | 两个结果区显示引导文案（不是空白）；上下文查询「我现在住哪里」后：顶部摘要条（查询文本/路由类型/综合分/命中 N/16），16 区块按「直接回答 / 观点与意图 / 推理链 / 证据与质量」四组渲染，每块带中文名 + 英文键名 + 一行释义；空区块收成组内灰字一行（如「本组未命中：相关事件 recent_events」）；长列表（causes 等）显示前若干条 + 「展开 N 条」；`current_state` 等顶到预算上限的块标「已截断(上限N)」；评分卡为雷达图（左）+ 维度条形（右）分栏，影响/因果/冲突/来源为条形图，时间链与影响链为可拖拽的关系图（箭头方向正确），事实行带置信度数值条。断网时图表位显示「图表库不可用」且链区块退回内联 SVG，明细不受影响 |
| 9 | 侧边栏「治理」 | 点「月度反射」（年 2026 月当前）→ 确认弹窗 | 结果区显示 `summary_id = N` |
| 10 | 侧边栏「治理」 | 点「模式提取」 | 结果区显示本次生成数；仪表盘「模式」计数变化 |
| 11 | 侧边栏「治理」 | 点「影响链推导」再点一次 | 第一次显示 ≥0 条；第二次幂等显示 0 条 |
| 12 | 侧边栏「治理」 | forget 目标=用户 原因=test → 点「遗忘」（确认） | 结果区显示 ok；再次查事实返回空 |
| 13 | 错误处理 | 查事实实体=不存在 | 空表格（不报错）；对不存在的 id 点「解释」→ 404 toast |
| 14 | 侧边栏「图谱」 | 打开图谱页 | 力导向图渲染节点与连线（节点 entity 蓝 / event 橙，边按 rel 着色）；工具栏 rel chips 可开关边显隐；拖拽/缩放可用；点击节点弹右侧抽屉（徽章/相邻节点列表/「解释」/「聚焦二跳」按钮）；子图模式输入中心节点名进入、退出还原全图；搜索定位节点高亮。断网或被墙时顶部出现「图表库 CDN 加载失败」横幅且「数据视图」表格可用 |

## 已知交互说明

- 治理按钮中 forget/compress-stable/reflect/restore/step-day 有二次确认弹窗
- token 存 localStorage；清除浏览器存储可重置
- hash 路由（`#/dashboard #/graph #/browser #/query #/write #/govern`）：可刷新、可收藏、支持参数跳转（如 `#/browser?explain=12&kind=node`）
- 图谱依赖 echarts CDN（bootcdn → npmmirror → staticfile → jsdelivr 四源降级链）；全部失败时横幅提示并降级为节点/边表格
- CORS 默认仅允许本机（127.0.0.1/localhost 任意端口），跨机前端需设 `DNAMEMORY_CORS_ORIGINS`
