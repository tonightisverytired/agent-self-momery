# M3 语义路验证报告：bge-m3 稠密检索 + 稠密/稀疏双向量存储

> 日期：2026-08-03｜阶段：M3 语义路 v1
> 模型：`BAAI/bge-m3`（1024 维稠密 + 词级稀疏权重，中文友好）
> 工具：[tools/mvp_llm_test.py](../tools/mvp_llm_test.py)（`--bge-m3`）、[tools/bge_m3_smoke.py](../tools/bge_m3_smoke.py)、[tools/paraphrase_demo.py](../tools/paraphrase_demo.py)、[tools/dense_tuning.py](../tools/dense_tuning.py)

---

## 1. 目标

1. 存储层同时承载**稠密向量 + 稀疏向量**（`node_vectors` 表）；
2. 数据写入时校验**稠密向量必须写入**，稀疏向量 best-effort 不做校验；
3. 三路召回的真实语义路用 bge-m3 稠密相似度，替代 M1 的词面重叠代理；
4. 验证"三路 ≥ 双路"门禁与同义改写场景下的实际收益。

## 2. 实现要点

- `embeddings.py`：`Embedder` 协议 + `BGEM3Embedder`（FlagEmbedding 惰性加载，本地缓存优先、首次联网下载）；`EmbeddingResult{dense, sparse, dim, model}`。
- `store.py`：新增 `node_vectors(node_id PK, dense TEXT, sparse TEXT, model, dim, updated_at)`；`set_node_vectors` 对稠密向量做非空校验（缺失抛 `E011`）；`fetch_node_vectors/has_node_vector`。
- `memory.py`：`add_event/add_entity/write_many` 写入节点后自动嵌入；`_embed_and_store` 批量计算，稠密写失败即报错，稀疏可空。
- `retrieval.py`：`_dense_path` 余弦相似度 + 阈值 `dense_min_sim=0.55` + 打分 `sim×(0.5+0.5×value_score)`；无 embedder 时回退旧词面代理，双路不受影响。
- `pyproject.toml`：`embed` extra（FlagEmbedding），numpy 沿用 `vector` extra。

维度 1024，稀疏键 2-10 个/句；本地缓存加载 16s，批量嵌入 ~1-2s。

### 3.2 写入校验（200 条导入）

- 节点向量：**300 条**（事件+实体全部写入），dim=1024，model=BAAI/bge-m3；
- 稠密向量缺失时抛 `E011`（单测覆盖）；
- 稀疏权重全部写入 JSON（numpy float32 → Python float 序列化已处理）；
- 模型重复加载走本地快照目录，不触发 HuggingFace 联网检查。

### 3.3 相似度分布与阈值调优（[dense_tuning.py](../tools/dense_tuning.py)）

主题查询下（80 个，真值=实体关联事件）：

| 集合 | n | p50 | p90 | max |
|---|---|---|---|---|
| 真值事件 | 260 | 0.679 | 0.777 | 0.935 |
| 非真值事件 | 15260 | 0.415 | 0.503 | 0.724 |

阈值/打分扫描（triple@5）：

| 阈值 | 打分 | Recall | MAP |
|---|---|---|---|
| 0.00 | sim×value | 0.979 | 0.940 |
| 0.55 | sim×value | 1.000 | 0.994 |
| 0.55 | sim×(0.5+0.5×value) | **1.000** | **1.000** |
| 0.60 | sim×(0.5+0.5×value) | 1.000 | 0.990 |

最终采用：`dense_min_sim=0.55` + blend 打分。

## 4. 结论与边界

**结论：M3 语义路 v1 落地并通过验证。** 稠密向量写入有强校验、稀疏向量随写随存；真实 bge-m3 稠密路让三路召回全面反超双路，并让旧代理完全失效的同义改写查询有结果。

边界与后续：
1. 当前为 numpy 暴力检索（300 节点秒级），规模化需 sqlite-vec/pgvector 索引；
2. 稀疏向量只存储未参与召回，BM25/SPLADE 稀疏路与稠密路做第四路融合留到 M3.1；
3. 闭环指标已饱和（1.000），后续收益需用人工标注 + 对抗/同义改写评测集度量；
4. 同义改写 top5 仍有噪声（如"通勤"类事件混入聚餐/加班），可继续调 `dense_min_sim` 或加入 rerank。
