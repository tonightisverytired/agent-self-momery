# 02 — 时空双螺旋模型

> **状态（2026-08-02）**：历史参考文档，已由 [00-长期个人智能体记忆系统方案.md](./00-长期个人智能体记忆系统方案.md) 取代执行地位；其中"碱基对/T链/S链"具象概念已被带类型关联边取代。

## 总结

DNA 双螺旋的两条互补链天然映射为时间和空间两个记忆维度。时间链（T-Strand / 5'→3'）承载事件序列和因果链，具有严格的方向性；空间链（S-Strand / 3'→5'）承载领域知识和实体关系，在概念空间中自由跳跃。碱基对是锚定在时空交叉点上的记忆节点——每个记忆原子同时带有一个时间坐标和一个空间坐标。两条链互补检索：给定时间可以溯因空间情境，给定主题可以回溯时间脉络，任一维度模糊时另一维度自动补救。

## 概况

传统的记忆系统（如 RAG 向量检索）只有一个检索维度——语义相似度。这意味着一旦语义维度模糊（查询词不精确、向量漂移、知识重叠），系统就失去了定位记忆的能力。DNA 双螺旋模型的核心贡献是提供**两个互补的检索维度**，使系统具有天然的抗遗忘噪声能力。时间链和空间链彼此独立但互相索引——就像 DNA 的两条链不直接相连，却通过碱基对精确耦合。

## 时间链 (T-Strand / 5'→3')

### 承载内容

T 链是记忆系统的"叙事轴线"。它承载：
- **事件序列**：对话轮次、操作步骤、动作日志
- **因果链**：事件之间的先后和因果关系
- **时间轴元数据**：时间戳、持续时间、重复周期
- **状态快照**：某一时刻的系统状态或上下文快照

### 方向性：从过去流向未来，不可逆

T 链的方向性是其最核心的特征。5'→3' 的方向映射为时间的箭头——过去的节点指向未来的节点，信息沿时间方向单向流动。这一设计确保了：
- 因果一致性：原因总是在结果之前
- 时序完整性：事件序列不可被篡改或重排
- 增量追加：新记忆总是追加在 T 链末端，不插入历史中间

### 数据特征

- **线性有序结构**：T 链本质是一个带有时间戳的有向序列
- **时间窗口切片**：支持按时间范围快速过滤——"过去一周"、"上个月"、"2025 年 Q3"
- **序列遍历**：支持沿时间轴前后扫描——"之后发生了什么？"、"在此之前"
- **事件聚类**：相邻时间窗口内的事件可以按会话或任务自动聚类

### 检索模式

T 链的典型检索场景：

| 查询类型 | 示例 | 检索策略 |
|---------|------|---------|
| 时间点定位 | "上周三下午我和张总讨论了什么？" | 时间戳精确匹配 → 时间窗口切片 |
| 时间范围扫描 | "这个月所有关于项目的讨论" | 时间范围过滤 → 关键词/向量二次过滤 |
| 因果追溯 | "这个决定之前发生了什么？" | 沿 T 链反向遍历 → 查找前序事件 |
| 趋势分析 | "最近一周我的工作重点是什么？" | 时间窗口聚合 → 主题提取 |

### DNA 类比

T 链对应 **sense strand（编码链）**——直接承载信息序列。在 DNA 中，编码链的序列与 mRNA 相同（T 替换为 U），直接决定蛋白质的氨基酸序列。在记忆系统中，T 链直接承载可供检索和推理的事件序列。

## 空间链 (S-Strand / 3'→5')

### 承载内容

S 链是记忆系统的"知识网络"。它承载：
- **领域知识**：概念定义、事实关系、专业术语
- **实体关系**：人物、项目、组织之间的关联网络
- **技能图谱**：操作流程的步骤分解和依赖关系
- **社会网络**：交互对象的身份、角色和关系权重

### 方向性：在概念空间间跳跃，无固定方向

与 T 链相反，S 链没有固定的遍历方向。它本质是一个图结构——从任一点出发，可以沿任意边探索。3'→5' 的方向在 DNA 中是酶沿模板链读取的方向，在记忆系统中象征"向概念深处追溯"。

### 数据特征

- **图结构**：节点是实体/概念，边是关系（属于、关联、类似、依赖）
- **子图展开**：从命中节点出发，展开 N 跳邻居获取完整上下文
- **加权边**：边的权重表示关系强度——频繁共现的关系权重高
- **动态拓扑**：随着新记忆写入，新节点和边被增量添加到图中

### 检索模式

S 链的典型检索场景：

| 查询类型 | 示例 | 检索策略 |
|---------|------|---------|
| 主题聚合 | "关于设计系统我知道什么？" | 概念节点匹配 → 子图展开 → 关联记忆收集 |
| 实体关联 | "李工程师和哪些项目有关？" | 实体节点定位 → N 跳邻居遍历 |
| 知识推理 | "微服务和单体架构的关系？" | 多跳路径探索 → 关系推理 |
| 相似性发现 | "还有哪些类似的技术方案？" | 图嵌入相似度 → 聚类发现 |

### DNA 类比

S 链对应 **antisense strand（模板链）**——被 RNA 聚合酶读取并进行转录。在 DNA 中，模板链被读取生成互补的 mRNA。在记忆系统中，S 链是被检索引擎"读取"的知识源——检索时沿 S 链遍历，定位相关的概念和实体。

## 碱基对：时空交叉点上的记忆节点

### 核心概念

每个碱基对 = 一个锚定在**特定时间坐标**和**特定空间坐标**上的记忆节点。它是 T 链和 S 链的交汇点——既知道"什么时候"，也知道"关于什么"。

### 两种配对的记忆学意义

| 配对类型 | 氢键数 | 稳定性 | 记忆学含义 | 适用场景 |
|---------|-------|-------|----------|---------|
| A=T (事实↔情境) | 2 | 灵活、易形成、可消退 | 临时记忆、会话上下文、一次性事件 | 对话记忆、临时笔记 |
| G≡C (技能↔概念) | 3 | 稳定、牢固、抗干扰 | 长期核心记忆、系统性知识 | 技能库、知识图谱 |

这一设计反映了记忆系统的实际需求：不是所有记忆都应该被同等牢固地保存。临时会话内容（A=T）应该可以自然消退，而核心知识（G≡C）应该持久稳定。

### 碱基对的生命周期

```
形成 → 巩固（增加氢键稳定性） → 衰减（端粒缩短） → 解离（自然遗忘）
```

- **形成**：新记忆写入时，T 链事件和 S 链实体自动配对
- **巩固**：频繁使用加强碱基对稳定性（类似于长期增强 LTP）
- **衰减**：长期未访问导致端粒缩短，增加解离概率
- **解离**：达到遗忘阈值时碱基对断开，记忆原子散落，等待端粒酶回收

## 双链互补：核心检索机制

### 核心洞察

> "DNA 最精妙的设计——任何一条链都包含重建另一条链的全部信息。"

这句话是双螺旋检索机制的理论基石。在记忆系统中：

- **T 链包含 S 链的索引**：每个时间点记录了当时涉及哪些主题、实体和概念
- **S 链包含 T 链的索引**：每个实体/概念记录了它曾在哪些时间点被讨论或操作

### T→S 溯因：给定时间，还原空间

**场景**：用户问"上周三下午发生了什么？"

1. 在 T 链上按时间戳定位上周三下午的时间窗口
2. 提取该窗口内所有事件节点的碱基对信息
3. 沿碱基对跨到 S 链，获取每个事件关联的实体和概念
4. 在 S 链上展开相关实体的子图，补充上下文
5. 合并结果：返回"上周三下午你和张总监讨论了项目 A 的预算问题，涉及供应商 B 和 C，结论是..."

### S→T 回溯：给定主题，追溯时间

**场景**：用户问"关于项目 A 有哪些讨论？"

1. 在 S 链上定位"项目 A"实体节点
2. 沿该节点的碱基对跨到 T 链，获取所有关联的时间点
3. 在 T 链上按时间排序，提取每个时间点的事件摘要
4. 合并结果：返回"项目 A 在 3 月启动讨论→4 月进行技术选型→5 月开始开发→6 月延期调整..."

### 抗遗忘噪声：一维模糊，另一维补救

这是双链模型最强大的特性。现实场景中：

- **时间模糊**："大概是上个月？也可能是两个月前..."——用 S 链的主题信息缩小时间范围
- **主题模糊**："那个关于什么微服务的讨论..."——用 T 链的时间线索回溯具体主题
- **双重模糊**：两个维度都模糊时，系统同时从两端发起近似搜索，取交集

```
抗遗忘能力公式：
  召回率 ≈ 1 - (1 - P_T命中) × (1 - P_S命中)
  
  其中 P_T命中 = 通过时间维度定位成功的概率
       P_S命中 = 通过空间维度定位成功的概率
```

当两个维度各只有 70% 的命中率时，联合召回率可达 91%。

## 时空双螺旋的形式化描述

### T 链的形式化定义

```
T = (V_T, E_T)   其中：
  V_T = {v_t1, v_t2, ..., v_tn}    事件节点，按时间戳排序
  E_T = {(v_ti, v_tj) | v_ti 先于 v_tj}   有向边："先于/后于"关系
  每个 v_ti 携带属性：(timestamp, event_type, summary, importance_score)
```

T 链是有向序列图。边是"先于/后于"关系，节点是事件。

### S 链的形式化定义

```
S = (V_S, E_S)   其中：
  V_S = {v_s1, v_s2, ..., v_sm}    实体/概念节点
  E_S = {(v_si, v_sj, w_ij)}       加权边：
    w_ij ∈ [0,1] 表示关系强度
    边类型 ∈ {属于, 关联, 类似, 依赖, 互斥}
  每个 v_si 携带属性：(entity_type, description, importance_score)
```

S 链是无向/加权图。节点是实体/概念，边表示语义关系。

### 碱基对的形式化定义

```
B = {(v_ti, v_sj, strength_ij)}   碱基对集合：
  (v_ti, v_sj) 是跨维度边，连接 T 链事件和 S 链实体
  strength_ij ∈ {2, 3}：
    2 = A=T 型（柔性配对，临时记忆）
    3 = G≡C 型（刚性配对，核心记忆）
```

### 本质：异构二部图

时空双螺旋在数学上是一个**异构二部图**（Heterogeneous Bipartite Graph）：

- 左部：T 链的事件节点
- 右部：S 链的实体节点
- 跨部边：碱基对
- 检索 = 在两部分之间交替游走（Alternating Walk）

```
检索路径示例（交替游走）：
  T链起点(时间点) → [跨链→] S链节点(实体) → [S链内跳转→] 相关实体
    → [跨链←] T链节点(相关事件) → [T链内遍历→] 前序/后序事件
```

## 与其他记忆模型的对比

| 维度 | 传统 RAG | 知识图谱 | DNA 双螺旋 |
|------|---------|---------|-----------|
| 检索维度 | 1（语义相似度） | 1（图遍历） | 2（时间 + 空间） |
| 抗遗忘 | 弱（模糊查询失效） | 中（依赖精确关系） | 强（双轨互补） |
| 时间感知 | 弱（无时间建模） | 弱（通常不建模时间） | 强（T 链专门建模） |
| 知识组织 | 扁平向量空间 | 图结构 | 图 + 序列双层 |
| 增量写入 | 简单追加 | 需要图合并策略 | 双链独立追加 + 自动配对 |
| 遗忘机制 | 手动删除 | 手动删除 | 端粒驱动的自动衰减 |
