# dnamemory 需求设计

> 版本：v2.0（2026-09-16）｜项目：长期个人智能体记忆系统（正式版 0.8.0）

## 1. 背景与目标

AI 智能体的上下文窗口有限，跨会话长期记忆是刚需。本项目从"DNA 双螺旋"概念出发，经过概念评估、模拟验证、MVP 验证与交叉验证，落地为**可嵌入、可调用、零配置的 Python 记忆库 `dnamemory`**：

- 0.3.0：以带类型关联边的记忆图谱为核心，多路召回、受控遗忘、冲突治理、访问控制、反射压缩；
- 0.5.0：**记忆 Runtime**——六类记忆对象分层（Fact/Belief/Intent/Evidence）、确定性状态解析、时间链、证据追溯、跨维度一致性；
- 0.6.0～0.7.0：跨月稳定记忆压缩、个人模式提取、影响链推导、同义 key 归一；
- 0.8.0：读写全能力 FastAPI（30 端点）、FastMCP 10 工具、**零构建静态后台**（六页可视化：仪表盘/图谱/浏览/查询/写入/治理）。

目标：

1. 可被其他系统调用：`pip install`、`import` 即可用，公共 API 稳定；
2. 可嵌入其他系统：进程内库（默认）+ FastAPI 侧车 + FastMCP 服务；
3. 零配置：所有可变配置在代码调用层显式传入，不读配置文件；
4. 业务严谨：事务、幂等、审计、状态机、并发安全，全量回归可复现。

## 2. 用户与使用场景

| 用户 | 场景 |
|---|---|
| 智能体应用开发者 | 为 Agent 接入长期记忆，跨会话记住用户偏好、事件与关系；用 `/context` 16 区块结构化上下文喂给 LLM |
| 个人助手服务 | 记录日常事件/事实/偏好，按时间、主题、语义召回；事实版本、观点演化、意图状态机可追溯 |
| 私有化部署者 | 进程内嵌入或本地 FastAPI/MCP 服务，数据不出本机；后台六页可视化浏览记忆图谱与治理 |
| 评测与集成人员 | 用内置评测集（五类能力 + 七类状态正确性）与双门禁脚本验证质量 |

## 3. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01 | 结构化写入 | 事件/实体/关联边/事实/观点/意图/影响/证据八类 + 批写（1-100 条），全部 `idempotency_key` 幂等 |
| FR-02 | LLM 拆解写入 | 日常文本 → 结构化记忆候选，逐条 Pydantic 校验，残缺候选只丢弃自身；`FallbackExtractor` 确定性兜底（无需 LLM 可测） |
| FR-03 | 多路召回 | 时间路 + 图谱路 + 稠密语义路 + 稀疏路（quad），RRF 融合 |
| FR-04 | 过滤链 | node_types / kinds / time_range / access_labels / relation 过滤 |
| FR-05 | 可选重排 | 注入 reranker 后对候选池重排，失败自动回退 |
| FR-06 | 生命周期 | active→archived→tombstoned→deleted 状态机，受控衰减、受保护节点、步进一天 |
| FR-07 | 受控遗忘 | 普通遗忘（墓碑）/ 合规删除（deleted 终态 + fact/edge 级联墓碑）/ 恢复节点 |
| FR-08 | 冲突治理 | 按来源可信级收敛同 key 事实，同源高置信进入确认流程（decisions → confirm） |
| FR-09 | 访问控制 | public/private/sensitive 三级，sensitive 默认隐藏，deleted 永不返回，全路径统一兜底 |
| FR-10 | 反射压缩 | 月度摘要（summarizes）+ 主题簇（part_of）+ 事实版本链（superseded_by）+ 跨月稳定记忆压缩 |
| FR-11 | 实体消解 | 同名实体合并（merge_similar 相似合并）、写入端点模糊匹配，边/事实重挂并审计 |
| FR-12 | 向量索引 | sqlite-vec 余弦 ANN，自动重建/增量同步，numpy 降级链 |
| FR-13 | 记忆 Runtime（0.5.0） | `recall_context()` 管线：候选扩展 → 状态解析 → 时间链 → 证据校验 → 一致性 → 16 区块结构化上下文；确定性 QueryRouter（当前/历史/时间线/变化意图）；当前事实由规则裁决（superseded_by→来源可信级→置信度→新鲜度），不依赖 LLM 与向量相似度；证据不足 abstain 不编造 |
| FR-14 | 六类记忆对象 | Event/Entity/Fact/Belief/Intent/Evidence；Belief 观点演化链不覆盖历史；Intent 独立状态机（active/completed/cancelled/expired/superseded）；Evidence 可追溯（inferred 强制标注推断） |
| FR-15 | 模式与影响 | 模式提取（四类规则：impact/temporal/preference/behavior，幂等）；影响链推导（impact_chains/causes）；跨维度一致性检查 |
| FR-16 | 服务化 | FastAPI 30 端点读写全能力（Bearer 鉴权、统一错误体、CORS 默认仅本机）+ **零构建静态后台**（六页：仪表盘分布图/图谱力导向可视化/分面浏览/查询台/写入/治理，echarts CDN 四源降级） |
| FR-17 | MCP | FastMCP 10 工具（recall/write_memory/forget/resolve_conflicts/context/timeline/explain/stats/write_structured/govern），stdio/streamable_http |
| FR-18 | 命令行 | 13 子命令：add-event/add-entity/add-edge/add-fact/recall/forget/reflect/demo/history/timeline/context/explain/eval；退出码 0/1/2 |
| FR-19 | 评测与门禁 | 中文五类能力评测（temporal/multi_hop/update/abstain/paraphrase，20 条）+ 状态正确性评测（26 条）+ 双门禁（快照召回 + 状态正确性） |

## 4. 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-01 | 零配置 | 核心功能无需配置文件/环境变量，默认值文档化 |
| NFR-02 | 可嵌入 | 进程内无服务依赖；可选 extras 拆分（vector/server/mcp/embed/llm/dev） |
| NFR-03 | 召回门禁 | 双路 Recall@5≥0.95、MAP@5≥0.90；三路 ≥ 双路；quad ≥ triple（2026-09-15 基线：dual/triple 均 Recall 1.000 / MAP 1.000） |
| NFR-04 | 噪声抑制 | 对抗查询 90% 零召回、平均误召回 ≤0.10 条 |
| NFR-05 | 同义鲁棒 | 无词面重叠改写查询 recall@5 ≥0.975（bge-m3 稠密路） |
| NFR-06 | 事务与幂等 | 写事务原子提交；idempotency_key 去重；审计全记录；0.4.0 旧库打开自动迁移（幂等补列建表） |
| NFR-07 | 安全 | Bearer token 常量时间比较；敏感记忆默认隐藏；SQL 参数化；错误体统一 `{code, message}` |
| NFR-08 | 可复现 | 评测固定 seed；门禁固定快照（缺失时自动生成确定性合成库） |
| NFR-09 | 零构建后台 | 无 npm/打包工具链；纯原生 JS + CSS；图谱 echarts 走 CDN 四源降级（bootcdn→npmmirror→staticfile→jsdelivr），全失败降级为结构化表格不影响功能 |

## 5. 边界与不承诺

- PostgresStore（写路径）本期只提供 DDL 与设计占位；查询侧已提供 PostgresTimeBackend / Neo4jGraphBackend；
- 可插拔后端为查询只读适配器，写入仍走 SQLite，由调用方显式注入并预置同步；
- LongMemEval 官方仓库适配器未启用，中文能力集为本期基准；
- 服务默认单进程单库，多进程共享同一库文件不在本期支持；
- 模型权重（bge-m3 约 2.3GB）不打包进 wheel，首次使用自动下载/缓存；
- 静态后台图谱依赖公网 CDN 加载 echarts；断网/被墙时降级为节点/边表格视图（验收清单第 14 步）；
- 开箱即用覆盖基础能力（双路召回/治理/CLI/API/后台）；语义、重排、服务化需要对应 extras。

## 6. 验收标准

1. `pytest` 全量通过（279 用例，含 0.5.0 状态层/时间链/一致性/服务/CLI/后台回归）；
2. `py ops/gate_check.py` 退出码 0 且快照召回指标达标；
3. `py ops/eval_longterm.py --bge-m3` 中文五类能力 recall=1.000（实测基线）；
4. `py ops/eval_state.py` 七类状态正确性全部 1.000（实测基线）；
5. `pip install .` 后 `dnamemory --version` 输出 0.8.0；
6. `dnamemory demo` + `ops/seed_rich_demo.py` 后可完成 add/recall/context/forget 全链路；
7. 后台按 [admin_checklist.md](admin_checklist.md) 14 步人工验收通过（含图谱可视化与 CDN 降级）；
8. 0.4.0 旧库打开自动迁移，旧功能全绿。
