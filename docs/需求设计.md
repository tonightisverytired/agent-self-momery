# dnamemory 需求设计

> 版本：v1.0（2026-08-03）｜项目：长期个人智能体记忆系统（正式版 0.3.0）

## 1. 背景与目标

AI 智能体的上下文窗口有限，跨会话长期记忆是刚需。本项目从"DNA 双螺旋"概念出发，经过概念评估、模拟验证、MVP 验证与交叉验证，最终落地为**可嵌入、可调用、零配置的 Python 记忆库 `dnamemory`**：以带类型关联边的记忆图谱为核心，提供多路召回、受控遗忘、冲突治理、访问控制与反射压缩等能力。

目标：

1. 可被其他系统调用：`pip install`、`import` 即可用，公共 API 稳定；
2. 可嵌入其他系统：进程内库（默认）+ FastAPI 侧车 + FastMCP 服务；
3. 零配置：所有可变配置在代码调用层显式传入，不读配置文件；
4. 业务严谨：事务、幂等、审计、状态机、并发安全，全量回归可复现。

## 2. 用户与使用场景

| 用户 | 场景 |
|---|---|
| 智能体应用开发者 | 为 Agent 接入长期记忆，跨会话记住用户偏好、事件与关系 |
| 个人助手服务 | 记录日常事件/事实/偏好，按时间、主题、语义召回 |
| 私有化部署者 | 进程内嵌入或本地 FastAPI/MCP 服务，数据不出本机 |
| 评测与集成人员 | 用内置评测集与门禁脚本验证召回质量 |

## 3. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01 | 结构化写入 | 事件/实体/关联边/事实四类数据可编程写入 |
| FR-02 | LLM 拆解写入 | 日常文本 → 结构化记忆候选，逐条 Pydantic 校验，残缺候选只丢弃自身 |
| FR-03 | 多路召回 | 时间路 + 图谱路 + 稠密语义路 + 稀疏路（quad），RRF 融合 |
| FR-04 | 过滤链 | node_types / kinds / time_range / access_labels / relation 过滤 |
| FR-05 | 可选重排 | 注入 reranker 后对候选池重排，失败自动回退 |
| FR-06 | 生命周期 | active→archived→tombstoned→deleted 状态机，受控衰减 |
| FR-07 | 受控遗忘 | 普通遗忘（墓碑）/ 合规删除（deleted 终态 + fact/edge 级联墓碑） |
| FR-08 | 冲突治理 | 按来源可信级收敛同 key 事实，同源高置信进入确认流程 |
| FR-09 | 访问控制 | public/private/sensitive 三级，sensitive 默认隐藏，deleted 永不返回 |
| FR-10 | 反射压缩 | 月度摘要（summarizes）+ 主题簇（part_of）+ 事实版本链（superseded_by） |
| FR-11 | 实体消解 | 同名实体合并、写入端点模糊匹配，边/事实重挂并审计 |
| FR-12 | 向量索引 | sqlite-vec 余弦 ANN，自动重建/增量同步，numpy 降级链 |
| FR-13 | 服务化 | FastAPI 侧车（Bearer 鉴权）+ FastMCP（stdio/streamable_http）+ 可插拔检索后端（TimeBackend/GraphBackend，默认 SQLite 零抽象开销） |
| FR-14 | 命令行 | add-event/add-entity/add-edge/add-fact/recall/forget/reflect/demo/eval |
| FR-15 | 评测 | 中文五类能力评测集（temporal/multi_hop/update/abstain/paraphrase）+ 门禁脚本 |

## 4. 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-01 | 零配置 | 核心功能无需配置文件/环境变量，默认值文档化 |
| NFR-02 | 可嵌入 | 进程内无服务依赖；可选 extras 拆分（vector/server/mcp/embed） |
| NFR-03 | 召回门禁 | 双路 Recall@5≥0.95、MAP@5≥0.90；三路 ≥ 双路；quad ≥ triple |
| NFR-04 | 噪声抑制 | 对抗查询 90% 零召回、平均误召回 ≤0.10 条 |
| NFR-05 | 同义鲁棒 | 无词面重叠改写查询 recall@5 ≥0.975（bge-m3 稠密路） |
| NFR-06 | 事务与幂等 | 写事务原子提交；idempotency_key 去重；审计全记录 |
| NFR-07 | 安全 | Bearer token 常量时间比较；敏感记忆默认隐藏；SQL 参数化 |
| NFR-08 | 可复现 | 评测固定 seed；门禁固定快照（缺失时自动生成确定性合成库） |

## 5. 边界与不承诺

- PostgresStore（写路径）本期只提供 DDL 与设计占位；查询侧已提供 PostgresTimeBackend；
- 可插拔后端为查询只读适配器（Postgres 时间链 / Neo4j 空间链），写入仍走 SQLite，由调用方显式注入；
- LongMemEval 官方仓库适配器未启用，中文能力集为本期基准；
- 服务默认单进程单库，多进程共享同一库文件不在本期支持；
- 模型权重不打包进 wheel，首次使用自动下载/缓存；
- 开箱即用覆盖基础能力（双路召回/治理/CLI/API）；语义、重排、服务化需要对应 extras（见开箱即用手册）。

## 6. 验收标准

1. `pytest` 全量通过（59 用例）；
2. `tools/gate_check.py` 退出码 0 且指标达标；
3. `tools/eval_longterm.py --bge-m3 --mode quad` 五类能力 recall=1.000（实测）；
4. `pip install .` 后 `dnamemory --version` 输出 0.3.0；
5. `dnamemory demo` 后可完成 add/recall/forget 全链路。
