## 一、模型变更摘要（相对 v1）

旧模型（v1，碱基对）已废弃，v2 采用带类型关联边：

| 维度 | v1 碱基对 | v2 关联边 |
|-----|----------|----------|
| 关联形态 | (事件, 实体, strength∈{2,3}) | (from, to, relation_type, weight, confidence, valid_at, invalid_at) |
| 关系语义 | 无类型 | 14 种类型枚举（participates/discusses/prefers/...） |
| 节点 | 事件 / 实体分属双链 | 统一异构节点（node_type + kind） |
| 生命周期 | 端粒计数挂在边上 | 节点 value_score + decay_rate + 生命周期状态机；facts 独立双时态 |
| 检索 | 双路（时间 + 图谱） | 三路（时间 + 图谱 + 语义代理），分数加权 RRF 融合 |
| 治理 | MMR 新者胜 | 双时态 + 可信源优先 + 同源高置信确认；TTL；墓碑；保护区 |

## 二、实验结果（2026-08-02 最终运行）

### 实验 1：召回率对比（240 查询）

| 路径 | 召回率 |
|-----|-------|
| 时间路 | 0.500（B 类主题查询不带时间提示，属预期） |
| 图谱路 | 0.517 |
| 双路（时间 + 图谱） | **1.000** |
| 三路（+ 语义） | **1.000** |

- 双路相对最佳单路提升 48.3 个百分点（0.517 → 1.000）。
- B 类（主题锚定）查询不再注入随机时间提示（MAP 实验发现：随机时间会使 B 类 MAP@5 从 0.960 跌到 0.458），与方案文档 5.2 节"路径激活规则"一致。

### 实验 2：抗遗忘噪声（5 种子 × 600 查询）

| 指标 | 数值 |
|-----|-----|
| 单维（仅图谱） | 0.055~0.078 |
| 双维（时间 + 图谱） | 0.648~0.688，**均值 0.670** |

结论：时间/主题各有 35% 被污染时，单维几乎失效，双维互补兜底有效。

**已知局限**：三维（+语义）在噪声场景为 0.537~0.587，低于双维。原因是模拟中的语义路用"词面重叠"代理真实 embedding，宽泛匹配会引入干扰；真实实现应使用 embedding 相似度 + 阈值（如 ≥0.7）后再启用语义路。该问题属于模拟代理精度，不是架构缺陷，已在方案文档第 5.2 节标注为待真实向量层验证项。

### 实验 3：生命周期 300 天（价值优先遗忘 + 保护区）

| 天数 | 核心记忆存活率 | 临时记忆存活率 |
|-----|-------------|-------------|
| 30~150 | 100% | 100% |
| 180 | 100% | 45% |
| 210 | 100% | 10% |
| 240+ | 100% | 0% |

- 核心记忆归档 0/20，临时记忆归档 40/40。
- 保护区偏好（咖啡/拿铁）300 天后仍 active，facts 全部有效——"价值优先 + 保护区"生效，不再像 v1 那样可能误删低频高价值记忆。

### 实验 4：角色/关系过滤

- "张总 participates 的邻居" → 预算会、技术选型会（类型精确过滤，非全文猜测）。
- "张总参与讨论的项目" → 项目A、项目B（participates → discusses 两跳推导）。
- "prefers 偏好查询" → 拿铁。

验证了关联边相对碱基对的直接收益：**关系类型让"谁参与、讨论什么、偏好什么"成为可查询的显式事实**。

### 实验 5：双时态矛盾策略

- profile"上海"（可信级 3）vs chat"慕尼黑"（可信级 1，时间更晚）→ 策略输出 resolved，活跃事实保持"上海"，慕尼黑被标记 superseded。
- 旧"新者胜"策略会错误回答"慕尼黑"。
- 同源双高置信（chat vs chat，0.9）→ confirm（要求用户确认，不自动裁决）。

### 实验 6：TTL 过期与显式撤回

- TTL 90 天的"85 折"事实过期后：活跃事实为空，检索不再返回。
- 用户撤回"旧项目/status"事实后：墓碑记录 1 条，检索彻底过滤，审计保留。

### 实验 7：旧碱基对 → 关联边迁移回归

- 迁移 120 条旧边：strength=3 → weight 0.9（15 条），strength=2 → weight 0.5（105 条），关系类型按事件/实体语义推断。
- 8 个主题查询回归：**0 降级**（新模型结果事件集 ⊇ 旧模型），迁移无损。

### 实验 8：指标集 + MAP 可行性（240 查询 + 噪声切片）

| 路径 | Recall@5 | Precision@5 | MRR | MAP@5 | NDCG@5 |
|-----|---------|------------|-----|-------|--------|
| 仅时间路 | 0.500 | 0.189 | 0.500 | 0.500 | 0.500 |
| 仅图谱路 | 0.529 | 0.458 | 0.473 | 0.444 | 0.461 |
| 双路 | **1.000** | **0.642** | **0.958** | **0.928** | **0.945** |
| 三路 | **1.000** | **0.689** | **0.998** | **0.993** | **0.996** |

- 分层 MAP@5：双路 A 时间锚定 0.987 / B 主题锚定 0.870；三路 B 提升到 1.000。
- 双路 MAP@5 bootstrap 95% CI：[0.901, 0.957]。
- 噪声切片（35% 污染）：双路 MAP@5=0.569、Recall@5=0.708——MAP 对提示质量敏感，可作为抗遗忘噪声的量化指标。
- 关键设计发现：无意义的时间提示会挤占主题查询排序（B 类 MAP 0.960→0.458），已固化为"路径激活规则"写入方案。
- 详细探究见 [docs/05-MAP可行性探究.md](../docs/05-MAP可行性探究.md)。

| 指标 | v1（碱基对） | v2（关联边） |

## 五、结论

带类型关联边模型在保留双维互补检索优势的前提下，补齐了碱基对缺失的关系语义、生命周期归属与双时态治理能力，所有验收项通过。指标体系（Recall/MRR/MAP/NDCG + 新鲜度/矛盾/遗忘合规）已建立并通过评测（详见 [docs/05-MAP可行性探究.md](../docs/05-MAP可行性探究.md) 与方案文档第 10 节）。模拟确认：**"碱基对"可以安全废弃，其合理内核（显式关联 + 强度 + 生命周期）由 edges 表完整承载。**
